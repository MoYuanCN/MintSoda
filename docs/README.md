## 常见问题入口

- **第一次安装**：见 [使用指南 · 运行与配置文件](USER_GUIDE.md#运行与配置文件) 或 [README 快速开始](../README.md#-快速开始)。
- **忘记密码 / 无法登录**：见 [使用指南 · 运行与配置文件](USER_GUIDE.md#运行与配置文件) 中首次启动与环境变量覆盖部分，以及 [常见问题与排查](USER_GUIDE.md#常见问题与排查)。
- **番剧没有下载**：先对照 [使用指南 · 标题匹配规则](USER_GUIDE.md#标题匹配规则) 的优先级，再检查插件过滤与反匹配未命中行为。
- **通知发不出去 / 订阅没更新**：见 [使用指南 · 常见问题与排查](USER_GUIDE.md#常见问题与排查)。
- **想写插件**：从 [插件开发指南](PLUGIN_DEVELOPMENT.md) 的概念与最小插件开始，示例见 `examples/plugins/`。
- **要接自动化脚本**：见 [API 参考](API.md) 的鉴权与接口清单。
- **迁移或备份配置**：见 [配置参考](CONFIG.md) 的文件说明与兼容字段，以及[使用指南 · 运行与配置文件](USER_GUIDE.md#运行与配置文件)。

## 维护约定

- 文档使用简体中文，术语保持一致：字幕组、反匹配、全局匹配、插件、扩展点、权限。
- 内部链接使用相对路径与 GitHub 锚点；标题改动时同步检查指向它的链接。
- 行为改动先改文档再改代码，或与代码同一提交更新；配置字段变更同时更新用户指南、配置参考与开发指南。
- 不在文档中写入真实凭据、令牌、配置、日志或本机路径，示例统一使用占位符。
